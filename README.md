# Кренометр — приложение для магнитолы

Показывает экраны кренометра (ESP32-S3 AMOLED 1.43, прошивка **3.13**) на Android-магнитоле:
кренометр, колёса, горизонт, одометр с компасом, трек, часы, G-метр — и терминал ELM327 через кренометр.
Справа — скорость, обороты, наддув, ОЖ, ATF, бортсеть.

## Пробег и моточасы
- Общий пробег (как одометр машины) и моточасы считает кренометр; выставить — ⚙ «Пробег и моточасы…» или `/odo?km=…&mh=…`.
- Хранятся в памяти платы и на карте microSD (если вставлена): `/krenometr/counters.txt`, `log.csv` (раз в минуту), `trips.csv` (поездки).
- Удержание на экране «Одометр» — новая поездка (общий пробег не сбрасывается).

APK собирается автоматически при каждом push: **Releases → Сборка N → Krenometr.apk**.

## Связь
- **Основной канал — кабель USB** от магнитолы к плате (прошивка 3.11+): питание и данные, Wi-Fi магнитоле не нужен.
  При первом подключении Android спросит «Открывать Кренометр для этого устройства?» — «Да», «По умолчанию».
- Без кабеля — по Wi-Fi (ниже).
- **GPS магнитолы** раз в секунду уходит в кренометр: путь подтягивается к GPS, а без скорости с ELM327 считается по скорости GPS.
- Сеть Wi-Fi `Krenometr` / `krenometr123`, кренометр — 192.168.4.1.
- Данные: UDP 4210, 25 пакетов/с (приложение раз в секунду шлёт `K1 w=0|1`).
- Команды: `/scr?on=0|1` экран, `/ap?on=0|1` сеть всегда, `/zero`, `/trip`, `/trk`, `/cmd` + `/cmdr` + `/cmdend` терминал, `/t?e=` время, `/info`.
- Интернет магнитола берёт с SIM: все сокеты приложения привязаны к Wi-Fi сети, остальной трафик идёт через SIM.
- Со старой прошивкой 3.9 работает урезанно (опрос `/a`, без колёс, G и трека).

## Первое подключение на магнитоле
1. Настройки → Wi-Fi → `Krenometr`, пароль `krenometr123`.
2. На вопрос «Сеть без доступа к интернету. Оставаться подключённым?» — **Да** и галочка «Больше не спрашивать».
3. Если магнитола всё равно отключается от сети — в приложении ⚙ → «Подключаться к Krenometr напрямую» (Android 10+).

## Управление
- Свайп по прибору — следующий экран; касание — сбросить максимумы; удержание — обнулить углы (кренометр, колёса, горизонт) или новая поездка (одометр, трек).
- ⚙ Настройки: экран кренометра вкл/выкл, режим сети, время, поворот экрана кренометра, сведения о прошивке.

Подпись — тем же `debug.keystore`, что у ELM CAN Терминала.
